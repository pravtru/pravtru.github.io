# pravtru.github.io

Статический сайт на GitHub Pages — генератор графических элементов инженерной/электротехнической документации по ГОСТ (со ссылкой на СП 333.1325800.2020 для формирования IFC-моделей). Без build-процесса и фреймворков: чистые HTML/JS/XML.

## Структура проекта

- **`index.htm`** — стартовая страница-описание с картой понятий: *Объект → Раздел → Элемент → Блок*.
- **`View.html`** — движок рендеринга. Через `?name=XXX` в URL подгружает `XXX.xml`, рекурсивно разворачивает вложенные `<Bl>`/`<Bl0>` (заменяя их содержимым соответствующего XML-файла с подстановкой параметров по `id`/`bid`), выводит итоговый SVG и исходный код на странице.
- **`Ob.htm` / `El.htm` / `Blok.htm`** — описания понятий "Объект", "Элемент" и "Блок", каждое дополнено таблицей-каталогом всех соответствующих XML-файлов со ссылкой "Просмотреть" (`View.html?name=...`) для предпросмотра.
- **XML-файлы в корне проекта** — библиотека графических элементов, разбитая на три типа: **Элементы** (`<El>`, каталог в `El.htm`), **Блоки** (`<Bl>`, каталог в `Blok.htm`) и **Объекты** (записи `<project>` внутри `Projects.xml`, каталог в `Ob.htm`). Полный список — см. ниже.
- **`bootstrap.min.css` / `bootstrap.bundle.min.js`** — вендорные библиотеки для UI (модальные окна выбора модели/параметров в `View.html`).

## Механизм подстановки блоков

Блок вызывается с параметрами, например:

```xml
<Bl Name="XT1"><Pr bid="1" transform="translate(0 0) rotate(0 0 0)"></Pr></Bl>
```

`View.html` рекурсивно ищет в вызываемом блоке элементы с атрибутом `id`, совпадающим с `bid` переданного параметра `<Pr>`, и заменяет их атрибуты/содержимое — то есть это самодельный шаблонизатор для SVG на чистом JS без зависимостей.
